Diagnóstico de Luces Nauta
🔴 EL PROBLEMA

✅ HTML offline: Guía visual de luces para TP-Link, Huawei, ZTE. Indica si el fallo es de ETECSA o del botón WLAN. IPs y claves por defecto listas para copiar.

📌 Uso inmediato: Abre el archivo sin internet. Mira las luces de tu router y compara con las imágenes.

✅ PDF de bolsillo: Árbol visual para identificar dominios falsos, textos de advertencia listos para reenviar al grupo, y lista de sitios legítimos cubanos.
💸 Coste evitado: Pérdida de saldo MLC (cientos de USD/EUR) · Suplantación de identidad
