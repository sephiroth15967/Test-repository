📡 Diagnóstico de Luces Nauta

PAU · Producto de Alta Utilidad (Offline)

Mira las luces de tu router Nauta Hogar y compara aquí. Funciona sin internet.

🔷 TP-Link (TD-W8961N / TD-W8951ND)
Power fijo verde + Internet rojo/apagado → Problema de ETECSA o línea. No toques nada. Espera.
Power verde + Internet parpadea verde rápido → Autenticando. Dale 3 minutos.
Luz WiFi apagada → Presiona el botón WLAN/WiFi del router.
🔑 Acceso al panel:
IP: 192.168.1.1
Usuario: admin / Clave: admin
🔶 Huawei (HG531 / HG532e)
Luz LOS roja fija o parpadeante → Fibra cortada o problema de ETECSA. Reportar.
Luz PON parpadea verde lento → Sincronizando. Espera 2-5 min.
Todas las luces verdes fijas pero sin internet → Reinicia el router desde el botón trasero.
🔑 Acceso al panel:
IP: 192.168.100.1 (o 192.168.1.1)
Usuario: telecomadmin / Clave: admintelecom
Usuario alternativo: root / admin
🔹 ZTE (F660 / F680)
LOS rojo → Sin señal de fibra. Contacta a ETECSA.
PON parpadea → Intentando conectar. No interrumpas.
🔑 Acceso al panel:
IP: 192.168.1.1
Usuario: user / Clave: user (o admin/admin)
⚡ Recomendación PAU: Si ninguna luz responde, desconecta el router 10 segundos y vuelve a conectar. Si tras 10 minutos no navega, reporta al 118 con el número de serie.
